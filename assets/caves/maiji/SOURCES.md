# 麦积山七处窟室的建模与图像

窟室以米为单位。来源中的洞窟尺寸指遗存观察或调查实测，浏览器中的宽深还包括窟前观察带。第13窟和第59号留露天崖面。第44、120、165窟保留残缺或狭小的洞窟尺度。现状、研究推定和浏览所需留地在每处的窟志面板说明。各互动点的原始依据列在 cave-maiji-records.js。
