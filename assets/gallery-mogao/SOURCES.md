# 莫高窟展墙图版来源

图版按现行窟号与拍摄对象登记。出处相同的窟可以有多个独立题材，登记中的每个文件都对应一幅实际图像。各展签注明所见细节与取景范围。第98窟的李圣天图既是五代馆独立展品，也供原窟的于阗供养人停靠点查看，同一文件只登记一次。
