# 麦积山 · 窟顶、佛座、弟子与龛铭

本次新增九件主展，其中西魏两件、北周三件、隋两件、宋一件，另有跨期展件一件。九件均有对应实物的影像。原有三十四件逐项比对后，另有五件增加七幅不同部位的对照图。目录中曾有简录的洞窟现在成为可实际参观的展位。各主展的断代、图片所见范围以及对读方式见 `records.js`。

## 选片和辨认

- **第27窟两张壁画。** 摄影图录分别著录为本窟壁画局部，两张均保留完整画幅；拍到的人物、建筑和横向分层在各自的图注中说明。窟顶北披法华经变的题材依据[上海音乐学院实地考察](https://zgysyyw.shcmusic.edu.cn/2018/1229/c2939a6331/page.htm)。旧照片本身未细标经品，所以展签没有给每一帧单独指定品名。
- **第26窟浮塑。** 旧摄影标为左壁佛台座浮雕飞天，田野报告记载两侧佛座分别有乐伎。画面有投影，细部残损，不据此判定所奏乐器。
- **第105和60窟。** 第105窟的菩萨与比丘为同一底片；第60窟的胁侍另在一龛。前者收在[麦积山造像通史](https://www.neac.gov.cn/seac/c103391/202302/1160985.shtml)的西魏窟群，后者按[项一峰的西崖实地窟志](https://ygx.sxu.edu.cn/db/%E6%9C%9F%E5%88%8A/dhxjk/dhxj2001/0101pdf/010106.pdf#page=3)。
- **第90窟。** [研究所学者的调查](https://ygx.sxu.edu.cn/db/%E6%9C%9F%E5%88%8A/dhxjk/dhxj2018/1804pdf/180408.pdf#page=3)区分早期窟龛和宋代重塑。原书题名为第90窟迦叶，所见为正壁佛侧弟子，归宋馆。未采用同一网络图录的“90号摩崖龛坐佛”，因其题名的窟形与现行总录记载的穹窿顶方窟不符。
- **第1、14及42窟。** [麦积区志卷下](https://www.gsdfszw.org.cn/gsxz/tss_270/mjq/202101/P020210129643376043243.pdf)记载东崖卧佛洞北魏开凿，唐、宋、明重修，存明代重修的涅槃像。名取摄于1956年的卧佛邻近人物片用于跨期馆，按实际照片范围说明。在第14窟的左壁，[刘丹的实地研究](https://ygx.sxu.edu.cn/db/%E5%AD%A6%E4%BD%8D/D01767911.pdf)著录了现存隋代力士；第42窟坐佛的原书题名与[隋代洞窟的分期记录](https://mooc1.chaoxing.com/mooc-ans/ztnodedetailcontroller/visitnodedetail?_fromV2_=&_from_=&courseId=214270353&knowledgeId=343765229&rtag=)共同使用。
- **庾信龛铭。** 拓片照片可辨右侧《秦州天水郡麦积崖佛龛铭并序》题名及中部“王父”“七佛龛”字样。《麦积区志》第五章碑铭条目辨明北周撰文和嘉靖四十三年重刻，展位按铭文归北周，照片说明标明是后世拓片的现代展场摄影。
- **第75窟候选予以搁置。** 1956年影像转载把一张壁画和一身菩萨都题为75号，而研究所总录第75窟条著录“摩崖浅龛，前部坍毁”，仅存残坐佛，无壁画。未把这两张材料加入现行75窟。第44窟现代展览所见的复制品也未作为原址主佛展示。
