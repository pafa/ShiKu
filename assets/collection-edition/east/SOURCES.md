# 云冈与龙门展品的原址图版

本目录的陈列图和放大图取自同一幅照片。每幅图的摄影者、文件页、许可及图注在 [plates.js](plates.js)，工作台另存原文件尺寸、实际下载尺寸、裁切区域与下载文件的 SHA-256。公开版成品的署名和 SHA-256 见[素材清单](../../credits.json)。原址照片由 Wikimedia Commons 作者发布，按其 CC0 或 CC BY-SA 4.0 许可等比缩放、转成 WebP。采用 CC BY-SA 的衍生图版沿用同一许可。原作页面和许可均可从展品的出处入口到达。

| 对象 | 本次核对与图像范围 |
| --- | --- |
| 云冈第8窟东侧摩醯首罗天 | 既有展位的照片拍的是对面的鸠摩罗天。新照片显示东侧骑牛护法，[浙江农林大学图书馆的窟号及两壁说明](https://lib.zafu.edu.cn/info/1148/4235.htm) 与[摄影者的壁位记录](https://commons.wikimedia.org/wiki/File:Datong_158.jpg)对得上。 |
| 云冈第9窟前室东壁交脚菩萨 | 中央菩萨的膝踝、龛楣与两侧小像均可辨。[摄影者的定位](https://commons.wikimedia.org/wiki/File:Datong_98.jpg)和[赵金超对同一张照片的图注及北魏分期](https://smarthistory.org/yungang-grottoes/)交叉核验。摄影者自述中的 “after 650” 与北魏断代冲突，年代据后者及[张焯对第9、10窟的解读](https://cul.china.com.cn/2020-06/01/content_41168486.htm)。 |
| 龙门第435龛摩崖三佛 | 新增对象是龛内独立的一身胁侍立像，比较同一雕像不同部位的加工状态。原有主展增补南侧坐像与旁侧立像的关系照。两张均为 Gary Todd 原址摄影。年代表述采用武周前后，参见[弥勒造像专题研究](https://ygx.sxu.edu.cn/db/期刊/20230419/24637_唐武周时期洛阳龙门石窟中弥勒造像的特征及原因.pdf)。 |
| 龙门奉先寺阿难像、天王座下夜叉 | 两尊雕像分别展出。阿难像有全身及独立面部机位，夜叉有伏地近景及与天王的组合照。[龙门石窟说明](https://en.lmsk.cn/Gywm)核对主像群的身份、年代及位置。 |
| 龙门看经寺 | 两张照片补原展站，镜头面对窟壁下部罗汉浮雕的不同部分。照片邻壁偶见残损或裂隙，没有据此推定具体祖师名次。[龙门石窟说明](https://en.lmsk.cn/Gywm)可核对29身罗汉的布局。 |
| 龙门奉先寺北宋窟前木构遗址 | 从原址正照等比裁取西壁头光两侧的方孔，与[窟檐遗迹调查](https://ygx.sxu.edu.cn/db/期刊/20230419/24618_龙门石窟大卢舍那像龛窟檐建筑复原设计研究.pdf)及[遗产保护规划中的北宋遗址登记](https://xcoss.henan.gov.cn/typtfile/20251222/bc7bf77bd7094dfea5d1efcbf9f5f54b.pdf)对读。照片可看壁上木构遗痕，地面柱础槽见调查图，方孔本身不能独立断代。 |

龙门擂鼓台南洞佛足迹碑开放原发表的[原照和墨拓](https://www.dpm.org.cn/journal/370567.html)。北洞第2062窟另有[具光学照片与湿度测量的研究图9](https://www.nature.com/articles/s40494-025-02181-0/figures/9)，其图组有非商业及禁止改作条件，保留为研究链接。对史密森尼 F1911.421 的千佛龛壁与克利夫兰馆藏帝、后礼佛拓本 1916.64 / .65，馆方记录提供可阅图像并列出使用限制，馆内使用各自的馆方原图入口。云冈上海博物馆天人头部与窟顶西区发掘照片同样链接原馆或原报告。尚不能按拍摄主体及开放条件独立核对的看经寺木构、云冈第38窟音乐树和第3窟“传祚无穷”出土瓦当，沿用图录或报告入口。

《牛橛造像记》图像来自[东京国立博物馆 ColBase · TB-665](https://colbase.nich.go.jp/collection_items/tnm/TB-665?locale=ja)。[日本文化厅同件记录](https://online.bunka.go.jp/heritages/detail/549440/114255)注明太和十九年十一月、尉迟氏为亡子牛橛造弥勒，以及纸本墨拓的尺寸。图版 E0053836 以 ColBase 提供的 1,520 × 3,000 全幅照片为母版，未裁切，等比转 WebP。图像按[ColBase 利用规约](https://colbase.nich.go.jp/pages/term)署名使用，[使用说明](https://cpcp.nich.go.jp/modules/r_free_page/index.php?id=122&lang=en)。495年是造像记所载的北魏原刻日期，墨拓的制作年代未据此指定。
