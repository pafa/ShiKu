# 麦积山展墙摄影

展图按可见部位著录。作者、许可、原始图版、文件摘要及转码说明另见仓库的公开素材清单。

| 展项 | 图像和鉴别依据 |
| --- | --- |
| 第98号摩崖 | Anagoria 于2016年在西崖拍下立像与胁侍，以及足下两团卷云。以《麦积区志》著录的立姿、云座和一侧胁侍核对。胸中钱币幡只在文字中描述。[立像](https://commons.wikimedia.org/wiki/File:2016-12-15_Maijishan_Grotten_麥積山石窟_anagoria_43.jpg) · [云座](https://commons.wikimedia.org/wiki/File:2016-12-15_Maijishan_Grotten_麥積山石窟_anagoria_46.JPG) · [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| 第120窟 | 原始研究图3a含坐像旁壁面的取样位置与样品放大图，图3c为样品截面。分别取原始分图。名取洋之助1956年拍摄的黑白照另有书目可查，公开素材包不收录该照片。[Wang 等，Crystals，2025](https://doi.org/10.3390/cryst15040339) · [名取原集书目](https://ndlsearch.ndl.go.jp/books/R100000002-I000000964605) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| 第28、30窟 | 使用2025年研究的图1E与图1I，保留色标、箭头和壁面原貌。作者把两窟合并著录，展签沿用此范围。图版仅约400×300像素，适合近看局部。关于初建分期，孙晓峰列为西魏，地方志列为北魏，另有研究据东崖层位提出[隋代分期](https://ygx.sxu.edu.cn/db/期刊/20260417/936麦积山石窟东崖大型洞窟的关系——以千佛廊为纽带的北周和隋代皇家石窟营造.pdf)。[调查论文](https://doi.org/10.3389/fmicb.2025.1657118) · [孙晓峰的分期](https://www.neac.gov.cn/seac/c103391/202302/1160985.shtml) · [地方志](https://www.gsdfszw.org.cn/gsxz/tss_270/mjq/202101/P020210129643376043243.pdf) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| 第4窟第四龛 | 图1C、D、E分别呈北侧菩萨、正中释迦牟尼、南侧菩萨。保留拍摄时所加观察标识。北周是崖阁营建时期，各像外层经历后代修整。[Duan 等，PLOS ONE，2017，图1](https://doi.org/10.1371/journal.pone.0179718.g001) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| 第5窟天王 | 区志按初唐造像、明代重妆著录。照片中可辨红须、双拳、胸甲与龛门，但牛犊位于取景之外。[Anagoria 的现场摄影](https://commons.wikimedia.org/wiki/File:2016-12-15_Maijishan_Grotten_麥積山石窟_anagoria_35.JPG) · [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| 第4窟金刚 | 摄影者标明第4窟宋塑金刚力士。区志另记长廊两端力士的身高、战裙支点及与壁面相连的木桩，其背面结构仅在文字解释。[Shizhao 的现场摄影](https://commons.wikimedia.org/wiki/File:Majishan_grotto_004_(4).jpg) · [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) |
