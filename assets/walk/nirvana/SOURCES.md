# 敦煌莫高窟第158窟

卧佛头南足北，面向东门。敦煌研究院的窟志记载原主室横长17.20米、进深7.28米，长坛高1.43米，石胎泥塑卧像长15.6米。涅槃像贴近西壁，真实佛坛占据主室西部。展馆保持佛像的长度、朝向、高坛和壁画的分壁关系。为让参观者绕行，展陈平面加宽至19.2米、加深至10.25米，并在原本贴壁的佛坛后和两端留出步道。观众站在这些虚拟站位可以近看原本位于像后的壁画。[敦煌研究院窟志](https://www.dha.ac.cn/info/1425/3663.htm) · [浙江美术馆敦煌展图录](https://www.zjam.org.cn/Topic/DunHuang/zyfg1.html)。

**原窟历史摄影。** 夏尔·努瓦特（Charles Nouette，1869–1910）1908年随伯希和调查团拍摄。Paul Pelliot, *Les Grottes de Touen-Houang*, Tome I, Paris, Paul Geuthner, 1920，旧编号19bis。图像文件使用 [Internet Archive 所藏 Public Resource / Pahar 副本](https://archive.org/details/dli.pahar.2105) 的原书扫描，原刊和努瓦特摄影现属公有领域。处理包括提取印刷画幅、校正朝向、局部透视校正、压缩和墨色调整。整体保留历史图版的明暗，展厅灯下的暖色为展陈色调。[图录及摄影者介绍](https://dsr.nii.ac.jp/toyobunko/VIII-5-B6-3/index.html.en)。

**复制陈列照片与造像曲面。** 中国美术馆第158窟复制陈列由 gongfu_king 摄影。[原始文件](https://commons.wikimedia.org/wiki/File:BeijingNationalArtMuseumofChina7.jpg) · [CC BY-SA 2.0](https://creativecommons.org/licenses/by-sa/2.0/)。head-color.webp 和 pillow.webp 分别裁自佛首和枕面，校正展柜偏暖的光色。west-registers.webp 在上层保留复制陈列中实际入镜的菩萨头光和面部，照片被卧佛遮挡的区域依窟志分层绘制，色层和细部属于当代释读。三个衍生纹理及展示它们的 interior.webp 采用 CC BY-SA 2.0。

**立体重建。** 前脸、发髻、额鼻、双枕、僧衣起伏、右手和交叠双足是有厚度的几何体，可以侧看和绕行。北壁倚坐弥勒的独立塑像据该窟三世佛配置做形制释读。身体体积、未摄入的衣背和躯干褶皱依据窟志、历史影像及原址照片推定。roof-fields.webp 为依盝顶曲面、成排小像和分格带补绘的展陈纹样。造像体积与缺失纹样的建模精度为释读级。[哈佛燕京图书馆所藏华尔纳1924年原窟摄影](https://library.harvard.edu/exhibits/langdon-warner-photographs-1924-dunhuang-expedition)用作造像与窟顶相对位置的参考。
