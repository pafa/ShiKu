# 云冈、龙门展品与图版

[逐幅摄影者、图注和许可](./plates.js)随[展签](./records.js)发布。图像沿用原有构图，转换为 WebP。文物的定名、出土地与照片本身所能证明的事项分别记录。

| 展签 | 实物和文献的核对 |
| --- | --- |
| 云冈「传祚无穷」筒瓦 | 照片包含瓦身、圆形当面和2010年出土的原展签。此处展示这一件完整筒瓦。旧站曾介绍第3窟前发掘的同铭瓦当，其尺寸、窟号及发掘记录均只适用于该标本。[现场照片与原签](https://commons.wikimedia.org/wiki/File:Datong_Yungang_Shiku_2013.08.29_15-49-57.jpg) · [同铭瓦当研究](https://ygx.sxu.edu.cn/db/期刊/sxdtdxxb-shkxb/sxdt2009/0906pdf/090611.pdf) |
| 云冈交脚菩萨比较 | 大都会艺术博物馆22.134，砂岩有彩迹，高146.1厘米。正面与侧面都是原馆图。旧卡片提出原属第25窟，原馆指出尚待研究。放在断代研读馆，供与云冈交脚像比较。[原馆藏品与两幅图](https://www.metmuseum.org/art/collection/search/42711) |
| 宾阳中洞门侧、奉先寺迦叶、看经寺壁基 | 使用Gary Todd按洞窟和对象逐张定名的原址摄影。核对门侧力士的手掌、迦叶立像缺损与看经寺台基上相邻僧人的手势。看经寺壁基图为既有展位的补充照片。[洞窟与群像](https://www.lmsk.cn/Gywm_id_5.html) |
| 药方洞南北两侧力士 | 摄影记录逐张区分门南、门北。所引研究区分洞窟多次营建、北齐风格主像和药方刻文，门侧两身的确切年代待考。[国家古籍保护中心](https://www.nlc.cn/pcab/xctg/bd/20190121_175422.shtml) |
| 武周时期宝冠坐佛 | 取2008年展场的原幅照片，可见高冠、臂钏和右手。展会新闻资料与引用同一照片的研究者对尊名给出不同释读，展签保留二者出处和原窟号的不确定性。[主办方](https://www.palazzostrozzi.org/mostra/cina/) · [展会新闻资料](https://www.deapress.com/ultime-nove-mainmenu-2/ufficio-stampa-mainmenu-68/3634-cina-alla-corte-degli-imperatori.pdf) · [同幅图的另一释读](https://smarthistory.org/maitreya/) |
| 看经寺窟前宋代建筑 | 2013年所摄门墙仅作现场位置对照。宋代木构已佚，柱础槽和梁孔的记载来自保护规划；本图没有拍到上述遗迹。[保护规划](https://xcoss.henan.gov.cn/typtfile/20251222/bc7bf77bd7094dfea5d1efcbf9f5f54b.pdf) · [门前现状摄影](https://commons.wikimedia.org/wiki/File:看经寺_-_panoramio.jpg) |
| 宋真宗《伊阙铭》 | 国家图书馆藏路朝霖辑《洛阳龙门志》，光绪丁亥（1887）开雕。数字本第2页为原书书名页影像，第8页为数字整理本的排印正文。年代馆以北宋作者与文章为主；近年的伊河照片仅作地形对照。[国家图书馆数字本](https://commons.wikimedia.org/wiki/File:NLC403-312001077490-94792_洛陽龍門志_清光緒13年(1887).pdf) |

另外复核了六项仍需从原机构阅读的展签。龙门擂鼓台南洞的佛足迹碑、弗利尔藏龛壁残件F1911.421、克利夫兰的帝后礼佛纸拓，以及云冈第38窟音乐树、上博第17窟天人头部、窟顶西区寺院遗址，目前保留各自的[原件记录或论文图版入口](../authentic/review-gaps.js)。查得的同题材照片无法证明为同件文物，或原馆没有给出可随开源库分发的逐图许可。
