两图均从 ShiKu RC1（提交 `a06accd0609e1fd5d3c894cb8b5825c64b81a44b`）在独立房间的 Chrome 浏览器实机截取。原生视口 1440 × 900，整幅转换为 WebP。可按下列署名转载。

## fengxian-walk.webp · 龙门奉先寺驻足路线

从展室的第一人称视角登阶，面前是三块摆放原址摄影的展面。ShiKu 设计了通道、空间布局和界面。合成截图按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 分享，署名 ShiKu、Zhangzhugang、G41rn8、Gary Todd。原始摄影等比转码后，在 3D 场景中按透视显示。
