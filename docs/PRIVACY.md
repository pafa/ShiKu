# 参观时会留下什么

入馆需要一个临时昵称和一个访客形象。建议使用化名。馆内其他人能看到你的昵称、形象、当前位置和最近最多 180 个移动轨迹点。排队者尚未出现在地图上。声音来自随站点提供的普通话音频，播放讲解无需麦克风。

## Cloudflare 公共房间

全站共用一个 Cloudflare Durable Object。为保证刷新、服务换版或房间进程重启后仍能续排、重连，房间的活动数据库保存候位顺序、临时票号、昵称、形象、在馆状态、会话令牌和最近保存的一处位置。连续移动时，服务器会在第一步及之后约每五秒记录一次位置，心跳也会更新这一处位置。同馆地图上看到的连续轨迹只在活动内存中保存；重连到重新启动的房间后，轨迹从最近保存的位置开始。

- 候位页面每隔约三秒查询一次。连续三分钟没有查询，票据过期并让出排位。
- 成功领取名额后，有十二秒建立首次连接。已连接的访客离馆时，房间会立即移除活动记录。直接断网或关闭页面时，已确认的会话从最后一次有效续期起最多保留九十五秒供重连。闹钟和后续请求负责清理到期数据，平台调度可能有延迟。
- 离馆、取消或超时后，为处理延迟和重复的登记，房间会额外保留短期请求编号约三分钟。该记录只含随机编号和过期时间。预计等待时间来自最近最多四十个已完成访问的时长及最近放行时间，不包含昵称。
- 活动表删除记录后，Cloudflare SQLite 仍有独立的时间点恢复窗口。根据 Cloudflare 文档，该机制可恢复过去三十天内的数据库状态。具备相应权限的运营方在此窗口内可能恢复此前的活动记录。该能力不适用于本地模拟器。[Cloudflare 时间点恢复说明](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/#pitr-point-in-time-recovery-api)

候位编号和票据保存在本标签页的会话存储中，用于刷新后恢复排位。完成入馆或主动退出排队后，页面会清除这份候位记录。登录页另会在本标签页会话存储里记住上次昵称，在此浏览器的本地存储里记住所选形象，供下次预填；可以清除该站点的浏览数据。访客令牌只用于自己的会话。请勿向他人分享票据或令牌。

## 本地 Node 版与外部服务

本地 Node 版将房间、候位和轨迹保存在服务进程的内存中。重启会清空当前房间和队列。可选 Nginx 配置的访问日志只含时间、请求方法、HTTP 状态和耗时。

Cloudflare 流量指标、边缘服务和运营方可能单独开启的日志各有保留策略。公开部署前，运营方应核实账号实际设置，并公布日志保留期和联系渠道。浏览馆方链接时适用相应网站的隐私条款。
