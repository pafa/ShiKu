# 社区行为约定 · Code of conduct

本约定适用于 ShiKu 的 issue、PR、评审和项目讨论。馆藏的断代、归属和释读可以有不同意见。指出具体作品、证据和推理，给对方回应或补充出处的机会。欢迎使用中文或英文提交问题，尊重初次参观者和贡献者的提问。

请使用尊重他人的语言。禁止骚扰、歧视、人身攻击、威胁、报复，以及公开他人的身份、联系方式、会话票据或行走轨迹。涉及自己参与创作、拥有权利或有商业关系的素材，请在讨论或审阅时说明关系。直接涉及争议的维护者应回避处理该报告。

如需报告 GitHub 上的行为，请保存相关内容的链接。在评论或用户页面选择 GitHub 提供的举报入口，或使用 GitHub Support 的举报表单。举报时仅提供处理所需的信息。若问题涉及维护者，可直接向 GitHub Support 报告。维护者可视情况提醒、隐藏不当讨论或限制项目内的参与，并在条件允许时由无利益冲突的人处理。[GitHub 举报指引](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)

## English

These expectations apply to issues, pull requests, reviews and project discussions. Cite the object, evidence and reasoning behind a disputed date or attribution. Give others room to respond and welcome questions from first-time visitors and contributors in Chinese or English.

Harassment, discrimination, personal attacks, threats, retaliation and sharing another person's identity, contact details, session tickets or movements are unacceptable. Disclose personal, commercial or rights-holder interests when proposing or reviewing material. A maintainer directly involved in a report should step aside.

To report conduct on GitHub, save a link and use the reporting option on the relevant comment or user profile, or the GitHub Support abuse form. Share only the details needed to assess the report. Reports involving a maintainer may go directly to GitHub Support. Maintainers may moderate content, issue a warning or restrict participation. Where possible, an uninvolved maintainer handles the report. [GitHub reporting guide](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
